Interventions - application Android (APK)

Compilation gratuite avec GitHub (rien a installer sur ton ordinateur) :
 1. Cree un compte sur github.com, puis un depot PRIVE (bouton "New", coche "Private").
 2. Dans le depot : "Add file" > "Upload files", glisse TOUT le contenu decompresse de ce zip
    (y compris le dossier .github), puis "Commit changes".
 3. Onglet "Actions" : la compilation "Build APK" demarre seule (3 a 6 min).
 4. Quand elle est verte, ouvre-la et telecharge "Interventions-apk" (un zip qui contient Interventions.apk).
 5. Sur le telephone : ouvre Interventions.apk et accepte "Installer des applications inconnues" pour ton gestionnaire de fichiers.

Au premier lancement :
 - autorise "Gestion de tous les fichiers" (enregistrement direct dans Documents/Gestion interventions),
 - autorise appareil photo, position et micro.

Ouvrir un OI : dans Gmail, appui sur la piece jointe PDF > Ouvrir avec / Partager > Interventions.
Les OI telecharges dans Download s'affichent aussi en liste dans l'appli (un appui pour les ouvrir).

La page est integree a l'APK (app/src/main/assets/page/interventions.html).
Mettre a jour la page sans recompiler : ouvre le nouveau interventions-vNN.html avec Interventions
(Fichiers ou Gmail > Ouvrir avec) : l'appli demande confirmation puis le copie dans
Documents/Gestion interventions/appli (elle prend toujours la page la plus recente).
Sauvegarde complete : Reglages > Sauvegarde complete (.zip) -> Telechargements/interventions_date_N.zip ;
ouvrir ce zip avec Interventions propose la restauration (date et versions affichees).
Pour une nouvelle version de l'appli : remplace les fichiers du depot et laisse GitHub recompiler ;
la cle de signature (app/interventions.jks) est la meme, la mise a jour s'installe par-dessus.
